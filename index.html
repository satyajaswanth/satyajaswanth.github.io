I work in computer architecture and non-volatile memory, with a focus on running useful computation — including on-device AI — on battery-less, intermittently-powered devices that lose power without warning.

I received my PhD from IIT Ropar (2018–2023) under Dr. Neeraj Goel and Dr. Mukesh Saini, and was a Postdoctoral Researcher at imec, Leuven, working on dynamic memory management for GPU and RISC-V architectures.

Research

My work lives where memory meets energy: keeping computation correct across power failures on battery-less devices, and designing efficient memory systems from the cache up to GPU and RISC-V allocators. A few ideas that run through it, in motion:

The 5-stage pipeline.

Instructions overlap so a new one issues every clock cycle.

IF · fetch → ID · decode → EX · execute → MEM · memory → WB · write-back

Intermittent Computing

Keeping programs correct across frequent, unpredictable power failures — checkpointing, safe resumption, and forward progress under tight energy budgets.

power-fail resiliencecheckpointing

Non-Volatile Memory

Architecting with PCM-RAM, STT-RAM and FRAM: placement/migration policies for hybrid caches and NVM main memory that retains state through power loss.

STT-RAMFRAM

GPU & RISC-V Memory

Dynamic memory managers and allocators for GPU and RISC-V architectures — the postdoc line of work at imec on efficient, intelligent allocation.

dynamic allocationRISC-V

Architecture Security & Embedded AI

Protecting control-flow integrity in RISC-V cores, and bringing memory-aware inference to microcontroller-class hardware running on harvested power.

CFIon-device AI
